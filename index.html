Pulse Bot: Market Scanner & Discord Alerts

An automated daily pipeline written in Python that tracks market pullbacks. It runs technical checks (including 200-day moving averages and RSI) to detect potential setups, then queries Gemini with search grounding to verify recent news headlines for sudden risks (such as profit warnings or unexpected management departures). Every weekday morning prior to market open, it formats a structured summary card and delivers it to a private Discord channel via webhooks.

Pipeline Workflow
Daily Execution Sequence
1. Ingest daily market time-series data
2. Compute 200-period SMA and 14-period RSI technical filters
3. Query Gemini with Google search to verify news context and filter high-risk drops
4. Dispatch formatted embed payload to Discord webhook with price targets and stop-loss levels
Implementation Details
  • Zero External Dependencies: Written entirely with Python standard library modules (urllib, json, math), keeping execution fast and maintenance minimal.
  • News Risk Verification: Uses Gemini with Google search grounding to verify price dips are not caused by severe negative corporate catalysts.
  • Automated Discord Webhooks: Posts structured embed cards with take-profit targets, stop-loss calculations, and reference links.
  • Scheduled Cloud Execution: Runs on GitHub Actions each weekday morning with timezone-aware idempotency locks and automated portfolio state tracking.
